# Reinforcement Learning Laboratory

This repository contains the implementation and documentation for the Reinforcement Learning Laboratory exercises using the Gymnasium library.

## Objective

The objective of this laboratory is to understand the fundamentals of Reinforcement Learning by interacting with Gymnasium environments, executing random actions, observing state transitions, rewards, and episode termination conditions.

## Technologies Used

- Python 3.x
- Gymnasium
- NumPy
- Matplotlib

## Learning Outcomes

- Understand Gymnasium environments
- Observe environment states
- Execute random actions
- Analyze rewards and episode termination
- Visualize Reinforcement Learning interactions
